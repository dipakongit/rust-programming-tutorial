## What is struct?
A struct is a type definition — it defines the structure of data but holds no real data itself. When you fill that structure with actual values, you get a real, usable copy of it, called an **instance**. For example:
```
fn main() {
    // Create a Struct called Student
    struct Student {
        name: String,    ────────────┐
        age: u32,                    | these are fields
        gender: String,  ────────────┘
    }

    // Create an instance of Student
    let student1 = Student {
        name: String::from("tom"),
        age: 32,
        gender: String::from("male"),
    };

    // Access and print the values
    println!("name : {}", student1.name);
    println!("age : {}", student1.age);
    println!("gender : {}", student1.gender);
}
```

### How can we change the value of a field in a mutable struct instance?
If the instance is mutable, we can change a value
```
fn main() {
    // Create a Struct called Student
    struct Student {
        name: String,
        age: u32,
        gender: String,
    }

    // Create an mutable instance of Student
    let mut student1 = Student {       ────────────┐
        name: String::from("tom"),                 |  The entire instance must be mutable.
        age: 32,                                   |  Rust doesn’t allow us to mark only 
        gender: String::from("male"),              |  certain fields as mutable
    };                                 ────────────┘

    // Change value
    student1.name = String::from("jerry");
    student1.gender = String::from("female");

    // Access and print the values
    println!("name : {}", student1.name);
    println!("age : {}", student1.age);
    println!("gender : {}", student1.gender);
}
```

### Using Field init Shorthand
```
// Create a Struct called Student
struct Student {
    name: String,
    age: u32,
    gender: String,
}

fn main() {
    // Create an instance of Student
    let student1 = create_student(String::from("tom"), 32, String::from("male"));

    // Access and print the values
    println!("name : {}", student1.name);
    println!("age : {}", student1.age);
    println!("gender : {}", student1.gender);
}

fn create_student(name: String, age: u32, gender: String) -> Student {
    Student {
        name,     // instead of name: name      ───────┐ parameter names and struct field name are the same, 
        age,      // instead of age: age               | so here we used the field init shorthand syntax.
        gender,   // instead of gender: gender  ───────┘ 
    }
}
```

### struct update syntax
#### Without `..`
You copy each field manually:
```
fn main() {
    // Create a Struct called Student
    struct Student {
        name: String,
        age: u32,
        gender: String,
    }

    // Create an instance of Student
    let student1 = Student {
        name: String::from("tom"),
        age: 32,
        gender: String::from("male"),
    };

    // copy age and gender field from student1 manually
    let student2 = Student {
        name: String::from("pop"),
        age: student1.age,
        gender: student1.gender,
    };

    // Access and print the values
    println!("name : {}", student2.name);
    println!("age : {}", student2.age);
    println!("gender : {}", student2.gender);
}
```
#### With `..`
Using struct update syntax (`..`), we can achieve the same effect with less code
```
let student2 = Student {
    name: String::from("pop"),
    ..student1
};
```
Create student2 with new name and take all other fields from student1.

#### How ownership work here?
Here, `name` is replaced with a new value. So the old `student1.name` is not moved to `student2`. Therefore, you can still use:
```
println!("name : {}", student1.name);
```
But `gender` was moved from `student1` to `student2`, so you cannot use:
```
println!("gender : {}", student1.gender); //// Error - ownership was moved to student2
```
But integer types like `u32` implement Copy Trait, so their values are copied rather than moved. Therefore, you can still use:
```
println!("age : {}", student1.age);
```

### Borrowing with Structs
```
struct Rectangle {
    width: u32,
    height: u32,
}

fn main() {
    // rect owns the Rectangle
    let rect = Rectangle {
        width: 10,
        height: 15,
    };

    // Give area() a reference to rect, so area() can use the
    //  data without taking ownership
    println!("The area of rectangle is {}", area(&rect));  
}

// Here rectangle is a borrowed reference to a Rectangle
fn area(rectangle: &Rectangle) -> u32 {
    rectangle.width * rectangle.height
}
```
