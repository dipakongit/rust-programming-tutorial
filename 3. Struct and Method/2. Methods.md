# Methods
Methods are similar to functions: We declare them with the `fn` keyword and a name, they can have parameters and a return value, and they contain some code that’s run when the method is called. 
```
struct Rectangle {
    width: u32,
    height: u32,
}

// impl is used to add methods to a struct.
impl Rectangle {
    
    // 1) area() is a method.
    // 2) A method must have a self parameter.
    // 3) A method can have multiple parameters, but the first parameter
    //   must be self, &self, or &mut self.
    // 4) &self - borrows the current Rectangle instance and allows reading its data.
    fn area(&self) -> u32 {
        self.height * self.width
    }
    
}

fn main() {
    let rec = Rectangle {
        width: 10,
        height: 15,
    };

    // Call method
    println!("{}", rec.area());
}
```
* **impl** - impl is used to add methods to a struct.
* **`area()`** - is a method.
  * A method must have a `self` parameter.
  * A method can have multiple parameters, but the first parameter must be `self`, `&self`, or `&mut self`.
    ```
     fn area(self)      // takes ownership
     fn area(&self)     // borrows and reads
     fn area(&mut self) // borrows and can modify
    ```

#### Exmple of `&mut self`
```
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&mut self) -> u32 {
        // `&mut self` - borrows the Rectangle mutably,
        // so the method can modify the values of its fields.
        self.width = self.width * 5;
        self.height * self.width
    }
}

fn main() {
    // Because the method uses `&mut self`,
    // the Rectangle instance must be mutable.
    let mut rec = Rectangle {
        width: 10,
        height: 15,
    };

    println!("{}", rec.area());
}
```

### What is differnce between function and method
The main difference is that a method belongs to a type, while a normal function does not. The easiest way to understand it is with the same task written as a function and as a method.

#### Function
```
struct Rectangle {
    width: u32,
    height: u32,
}

fn area(rectangle: &Rectangle) -> u32 {
    rectangle.width * rectangle.height
}

fn main() {
    let rec = Rectangle {
        width: 10,
        height: 15,
    };

    println!("{}", area(&rec));
}
```
Here `area` is a normal function. The function does not belong to `Rectangle`. We pass the `Rectangle` to the function

#### Method
```
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.height * self.width
    }
}

fn main() {
    let rec = Rectangle {
        width: 10,
        height: 15,
    };

    println!("{}", rec.area());
}
```
Here `area` ia a method of `Rectangle`. It belongs to `Rectangle` because we defined it inside:
```
impl Rectangle {
    // methods here
}
```

### Method with More Parameters
```
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // A method can have multiple parameters, 
    //  but the first parameter must be `self`
    fn increase_area(&self, extra: u32) -> u32 {
        (self.width + extra) * (self.height + extra)
    }
}

fn main() {
    let rec = Rectangle {
        width: 10,
        height: 15,
    };

    println!("{}", rec.increase_area(5));
}
```

### Create multiple methods inside the same `impl` block
```
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    fn area(&self) -> u32 {
        self.width * self.height
    }

    fn increase_area(&self, extra: u32) -> u32 {
        (self.width + extra) * (self.height + extra)
    }
}

fn main() {
    let rec = Rectangle {
        width: 10,
        height: 15,
    };

    println!("{}", rec.area());
    println!("{}", rec.increase_area(5));
}
```

### Multiple `impl` blocks
```
struct Rectangle {

impl Rectangle {
```

### Associated Functions
```
struct Rectangle {
    width: u32,
    height: u32,
}

impl Rectangle {
    // method
    fn area(&self) -> u32 {
        self.width * self.height
    }

    // Associated function - associated with the `Rectangle` type
    fn square(size: u32) -> Self {
        Self {
            width: size,
            height: size,
        }
    }
}

fn main() {
    // Call associated function using the type name
    let rec = Rectangle::square(10);

    // Call method
    println!("{}", rec.area());
}
```
* All functions defined inside an `impl` block are called **associated functions** because they are associated with the type written after `impl`.
* An associated function does not use `self` as its first parameter 
* An associated function is called using the type name with `::`.
