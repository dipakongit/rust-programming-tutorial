# Enum
## What is Enum?
An enum represents a value that can be one of several possible choices (variants).   

For example, an IP address can be either **IPv4** or **IPv6**, so an enum is suitable.
```
enum IpAddrKind {
    V4,  ────────────┐these are variants
    V6,  ────────────┘
}
```
Here, **V4** and **V6** are called **variants**.

### Creating Enum Values
```
let ipv4 = IpAddrKind::V4;
let ipv6 = IpAddrKind::V6;
```
`::` is used to access an enum variant.

### Enum with function
We can also pass any variant to a function:
```
fn route(ip: IpAddrKind) {}

route(IpAddrKind::V4);
route(IpAddrKind::V6);
```

### Enum with data
An enum variant can also store data.
```
enum IpAddr {
    V4(String),
    V6(String),
}

let localhost = IpAddr::V4(String::from("127.0.0.1"));
let loopback = IpAddr::V6(String::from("::1"));
```
#### Different Variants Can Store Different Data
```
enum IpAddr {
    V4(u8, u8, u8, u8),
    V6(String),
}
```
Here:
* **V4** stores four u8 values
* **V6** stores one String
```
let localhost = IpAddr::V4(127, 0, 0, 1);
let loopback = IpAddr::V6(String::from("::1"));
```

#### An enum variant can store almost any type of data inside it.
1. Variant can contain a **String**
    ```
    enum Message {
        Write(String),
    }
    
    let msg = Message::Write(String::from("Hello"));
    ```
2. Variant can contain numbers
    ```
    enum Rgb {
        ChangeColor(i32, i32, i32),
    }
    
    let rgb = Rgb::ChangeColor(255, 0, 0);
    ```
3. Variant can contain a struct
    ```
    struct Point {
        x: i32,
        y: i32,
    }
    
    enum Action {
        Move(Point),
    }
    
    let action = Action::Move(Point { x: 10, y: 20 });
    ```
4. Variant can even contain another enum
    ```
    enum Direction {
        Up,
        Down,
    }
    
    enum Action {
        Move(Direction),
    }
    
    let action = Action::Move(Direction::Up);
    ```

### Methods on Enums
An enum can have variants with completely different data:
```
enum Message {
    Quit,
    Move { x: i32, y: i32 },
    Write(String),
    ChangeColor(i32, i32, i32),
}
```
* **Quit** No data
* **Move** x and y fields
* **Write**	One String
* **ChangeColor**	Three i32 values

Even though the variants contain different data, all of them have the same type: `Message`. This is useful because a function can accept any kind of `Message`:
```
fn process(message: Message) {
    // ...
}
```

Just like structs, we can define methods for enums using `impl`.
```
impl Message {
    fn call(&self) {
        // method body
    }
}

let m = Message::Write(String::from("hello"));
m.call();
```

### The `Option` Enum
Option enum (`Option<T>`) is a built-in enum provided by Rust's standard library. You don't create it yourself. It is used when a value may exist or may not exist.  

`<T>` means Option can hold a value of any type

#### Option enum (`Option<T>`) have two Variants:
* **Some(value)** - value exists
* **None** - no value

#### Example
```
let some_number = Some(5);        // Option<i32>
let some_char = Some('e');        // Option<char>

let nothing: Option<i32> = None;
```
* **Some(5)** → Rust knows the type is i32.
* **Some('e') → Rust knows the type is char.
* **None** → Rust cannot know the type because there is no value, so we may need to specify the type.  
  `Option<i32>` means: it can contain an `i32` value, or can contain nothing

#### Why can't we directly use `Option<T>`?
`Option<i32>` and `i32` are different types:
```
let x: i32 = 5; 
let y: Option<i32> = Some(10); 
let sum = x + y; // Error
```
First, we need to handle whether `y` is `Some` or `None` using `match`. We will learn how to do this in the `match` chapter.
