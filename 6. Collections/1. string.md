## Defining Strings
Rust mainly uses two string types:
1) `&str`
2) String

Both store text using **UTF-8** encoding.

```
fn main() {
    let s1: &str = "Hello";
    let mut s2 = String::from("Hello");

    s2.push_str(" World"); // modify String type

    println!("{s1}"); // Hello
    println!("{s2}"); // Hello World
}
```
**Remember:** 
* **&str** — borrowed string, usually cannot be modified through the reference.
* **String** — owned string that can grow and be modified when declared `mut`.

## Creating a New String
Rust provides several ways to create a `String`.

#### 1) Create an empty String
```
let s = String::new();      // immutable string
let mut s = String::new(); // mutable string
```
#### 2) Create a String using `to_string()`
```
let data = "hello world";

// Convert &str to String
let s = data.to_string();

// You can also convert directly from a string literal
let s = "hello world".to_string();
```
#### 3) Create a String using `String::from()`
This does the same thing as to_string() in this example.
```
let data = "hello world";

// Convert &str to String
let s = String::from(data);

// Create a String directly from a string literal
let s = String::from("hello world");
```

**Remember:**  
* `String::new()` creates an empty string.
* `to_string()` and `String::from()` create a String from text.
* Use `mut` if you want to modify the string.
* Strings use **UTF-8** encoding, so they can store text from different languages, including Hindi, Bengali, Arabic, Chinese, and Japanese.

## Updating a String
A String is growable and mutable. You can add text using `push_str()`, `push()`, the `+` operator, or the `format!` macro.

#### 1) Using `push_str()`
```
let mut data = String::from("hello");
data.push_str(" world");
println!("{data}");
```
**Important:** `push_str()` does not take ownership of the passed string slice, so you can still use it afterward.
```
let mut s1 = String::from("hello");
let s2 = String::from(" world");

// as_str() convert String to &str
// Append s2's text to s1 without taking ownership of s2
s1.push_str(s2.as_str());

println!("{s1}");
println!("{s2}"); // s2 is still usable afterward
```
#### 2) Using `push()`
```
let mut s1 = String::from("hell");

// Adds a single character (char) to the end of a String.
s1.push('o');

println!("{s1}");
```

```

```
**Remember:**  
* `format!` returns a new String.
* It does not take ownership of the variables used inside it, so you can use them afterward.
* Prefer `format!` when combining multiple strings because it is easier to read.

## Slicing Strings
```
let s = String::from("hello");

// use a range start..end to get a part of a string as a &str.
let slice = &s[0..2];
               |  |
               |  end
               start
```
* String ranges use byte positions. Here, `0..2` selects the first 2 bytes, so it prints `he`, because each English letter in "hello" uses 1 byte in UTF-8.

#### The problem with string slicing
In Rust, string slicing uses byte positions, not character positions.
```
let s = String::from("नम");
let slice = &s[0..3];
println!("{slice}"); // न
```
This works because `न` uses 3 bytes in UTF-8.   

But if you try:
```
let s = String::from("नम");
let slice = &s[0..1]; // Panics at runtime!
```
Why does `0..1` panic? Because it selects only the first byte of `न`, not the complete character.  

To see the bytes, use `as_bytes()`:
```
let s = String::from("न");
println!("{:?}",s.as_bytes());
// [224, 164, 168]
```
The output (`[224, 164, 168]`) contains 3 bytes because `न` uses 3 bytes in UTF-8.   

## Iterating Over Strings
#### Use `.chars()` to work with characters
For general text processing, use `.chars()` when you want to work with Unicode characters rather than byte positions.
```
let s = String::from("नम");
for c in s.chars(){
    println!("{c}");
}
```
Get a particular character. 
```
let s = String::from("नम");
let first = s.chars().nth(0);
let second = s.chars().nth(1);
println!("{:?}", first);
println!("{:?}", second);
```
* `.nth()` counts Unicode char values, not bytes. 
* It returns `Option<char>`, so the result is `Some('म')` or `None` if the character doesn't exist.
* `.nth()` starts counting from 0.

#### Use `.bytes()` to get individual bytes
The .bytes() method returns each individual UTF-8 byte, not each character. 
```
let s = String::from("नम");
for b in s.bytes() {
    println!("{b}");
}
```

Use `.chars()` for character-based text processing and `.bytes()` when you need to work with the underlying UTF-8 bytes.
